# Guia de Prescrição de NPT — Adulto

Ferramenta web local para auxiliar a composição inicial de Nutrição Parenteral Total (NPT) em adultos.

## Características

- Funciona inteiramente no navegador.
- Não possui backend.
- Não envia, armazena ou registra dados clínicos.
- Sugere cota calórica e proteína.
- Calcula macronutrientes, eletrólitos e respectivos volumes.
- Considera glicemia, triglicerídeos, função renal, diurese, balanço hídrico, risco de realimentação e propofol.
- Exibe alertas e justificativas clínicas.
- Usa ESPEN e ASPEN como referências principais.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, escolha a branch principal (`main`) e a pasta `/root`.
4. Salve e aguarde a publicação.

## Aviso

Ferramenta de apoio à decisão clínica. A composição final da NPT deve ser individualizada e revisada pelo médico e pela farmácia responsável pela manipulação, especialmente quanto à compatibilidade cálcio-fósforo, concentração final, osmolaridade e apresentações locais dos componentes.
